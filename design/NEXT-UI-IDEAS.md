# 后续美化建议（尚未实施）

0.4.0 本轮只落实快捷记账、支出分析及文案精简。下面三项供后续选择，不改变本轮配色与整体视觉。

1. **统一选中颜色**：分类、明细/分析、币种控件统一使用现有薄荷绿，减少绿色与默认紫色选中态同时出现。
2. **压缩账单列表**：同一天的账单分组，左侧分类图标与备注，右侧金额；减少每笔记录的卡片高度，保留大字体下换行。
3. **减少分析页大卡片**：月份选择使用紧凑工具栏，把支出总额、对比和图表作为连续区域；分类继续用可点击的条形图呈现，增强金额与辅助信息的字号层级。

本轮实际界面可查看 `folio-0.4-runtime-entry.png`、`folio-0.4-runtime-analysis.png` 和 `folio-0.4-runtime-categories.png`，图中均为独立模拟器上的虚构测试数据。
