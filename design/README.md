# Folio 第一版界面改造

此文件记录 0.1 版的视觉研究。当前 0.4.0 已支持快捷分类、日历记账、上次账户和支出分析，并精简重复文案。底部导航为总览、资产、账单，设置位于右上角。使用方法见 [功能说明](../FUNCTIONALITY.md)。下方图像保留为早期视觉参考。

研究与改造日期：2026-10-21。

这一版沿用个人多币种资产管理的定位：先看总额，再看期间变化，最后进入资产明细。主要视觉为森林绿与薄荷绿，浅色采用暖白底色。现有模拟资产、固定汇率、三栏导航及筛选/详情操作继续作为界面内容。

## 参考及采用的原则

| 官方参考 | 本轮观察 | Folio 中的应用 |
| --- | --- | --- |
| [Wealthfront 产品页面](https://www.wealthfront.com/) | 产品截图突出总额，把趋势和分配放在金额之后，装饰较少。 | 总额作为首要视觉；金额、期间变化及曲线组成一个连续区域。 |
| [Copilot Money Accounts Tab Overview](https://help.copilot.money/en/articles/6213732-accounts-tab-overview) | 顶部趋势可切换期间，账户按类别组织，并可查看节点。 | 明确的周期选中状态、可选节点、按资产类别进入列表。 |
| [Wise 账户界面更新说明](https://wise.com/help/articles/645Ve1Ah1Psi0srHGfKYmm/your-wise-account-has-a-new-look) | 首页强调币种及分组，帮助辨认钱在哪里。 | 总额旁标注展示币种，详情区分折算估值与原币报价。 |
| [Material Design 3](https://m3.material.io/) | Android 的颜色角色、排版和组件体系。 | 共用主题、卡片、选择控件和导航；深浅主题使用同一组语义角色。 |

上述是从公开界面提取的设计原则和本项目的设计判断；项目未复制这些产品的商标、截图或专有素材。资产与账户类型不同，本轮只采用适合现有模型的部分。

## 已实现

- 总览：合并资产估值和趋势，明确期间资产价值变化；零基期比例显示“—”，空历史不索引越界。
- 分布：比例条和可点击的分类明细；总额为零时使用空的中性轨道。
- 持仓：每个资产有稳定列表 key，真正按条目惰性加载；窄屏和大字体采用纵向金额布局。
- 详情：展示币种、估值、数量及原币价格明确分组，长文本允许换行。
- 设置：币种和主题使用整行单选，模拟汇率独立说明。
- 交互：保留页面切换、筛选和详情返回；再次点击资产页签不清空已有筛选。
- 图表：160dp 高，点击/键盘/读屏节点选择；空、单点、常数历史安全；以十进制差值归一化，避免大额微小变化在转换 Float 时丢失。
- 主题：统一字号、边框、间距与表面颜色；系统栏图标样式随应用主题切换。

界面改造阶段执行了 Kotlin 语法解析、源代码交叉检查与 SVG XML 解析。2026-10-21 随后完成实际 Kotlin/Compose 编译、调试 APK 打包和 5 个单元测试，APK 签名验证通过。详情见 [构建验证记录](../BUILD-VERIFICATION.md)。
